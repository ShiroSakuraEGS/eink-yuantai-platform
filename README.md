---

## 🌟 核心特色功能

1. **⚡ 全頁電子紙刷新波形特效（E-Ink Waveform Flash）**
   - 模擬真實電子紙全頁刷新（Full Refresh）消除殘影時的經典黑白翻轉波形動畫。
2. **🔬 電泳微膠囊 3.0 物理模擬器與即時示波器**
   - 支援 `+V`（顯白）、`-V`（顯黑）、`~V`（灰階微脈衝混合）與 `0V`（雙穩態斷電維持）物理動畫。
   - 內建即時驅動波形時序圖（Live Waveform Oscilloscope）。
   - 環境光照度（Lux）光學模擬滑桿（對比 E-Ink 陽光反射 vs LCD 泛白眩光）。
3. **🎨 彩色電子紙四大架構即時模擬工作室（Color Studio）**
   - 一鍵切換對比 Carta 1200、Kaleido 3 (CFA)、Gallery 3 (ACeP) 與 Spectra 6。
   - 內建微觀光學放大鏡（Loupe），直觀觀察彩色濾光片網格與彩色粒子團簇。
4. **📖 20 大核心技術名詞全檢索字典**
   - 包含顯示原理、硬體驅動、彩色光學與終端應用四大領域，支援即時關鍵字高亮搜尋與分類篩選。
5. **⏳ 1990 ~ 2026 技術演進時光軸**
   - 收錄 13 個關鍵歷史節點（MIT 實驗室、Sony 首發、Carta HD、2026 Spectra 6 面積突破黑白），皆附官方來源佐證。
6. **🔄 系統拓撲雙資料路徑 ✕ 晶片節點詳細檢測器**
   - 視覺化呈現「本地離線」與「手機/雲端 AI 協同」兩種資料流向，點擊節點即可查看晶片功耗與通訊協定規格。
7. **🔋 BLE ✕ 輕量電源互動試算模擬器 3.0**
   - 內建 4 組熱門情境預設（超商 ESL、員工識別證、桌面看板、無電池 NFC），並提供每日能耗佔比拆解長條圖。

---

## 🛠️ 技術架構

- **前端核心**：Vanilla HTML5, CSS3, JavaScript (ES6+)
- **繪圖渲染**：Canvas 2D API (粒子物理引擎、示波器、微觀濾波器演算法)
- **零依賴套件**：無第三方龐大框架，極速載入、極致效能
- **跨平台響應**：支援行動端抽屜選單與桌面端流暢微互動
